# 连续注视：实现与素材边界

更新：2026-09-14。

## 这次采用的机制

鼠标桌面像素坐标经过当前窗口DPI变换，以站立/坐姿各自的头部中心归一化，持续输出横向和纵向目标。眼部和头颈使用不同的平滑时间常数；不再由“停留多久”触发方向视频。

控制思路参考“持续目标坐标 + 可控阻尼 + 绑定到模型参数”，可参照 [Live2D LookAt 官方说明](https://docs.live2d.com/en/cubism-sdk-tutorials/lookat/)。本程序是独立WPF实现，不包含Cubism SDK，也没有生成或冒充`.moc3`模型。眼球和头部应独立控制的参数划分可参照 [官方标准参数](https://docs.live2d.com/en/cubism-editor-manual/standard-parameter-list/)。

图像使用现有320×480站立/坐姿原纹理。连通网格对头颈小幅连续形变，向胸颈衔接区衰减；下半身、前爪和尾巴固定。没有把一段头部视频贴回静态身体，也没有更换原始照片或视频。眨眼、照顾和姿势转换继续使用完整原速视频，不用压合眼周网格伪造眨眼。

本版只解决连续响应和桌面集成，仍是小幅2D近似。虹膜尚未独立分层，不能从一张照片真实恢复不可见侧脸、眼球转动或大幅俯仰。

## 若要继续提高自然度

下一步应准备可绑定的分层模型，而不是单纯追加几段完整环顾视频：

- 同一坐姿的身体底层、连续头颈层。
- 左右眼内部底图，以及独立虹膜/瞳孔层。
- 左右上、下眼睑及眼部遮罩，避免移动整块眼眶。
- 眼球移动后露出的区域、耳后和颈部遮挡区域的合理补绘。
- 同一身份、镜头与光照的左右、俯仰参考，用于校对有限范围内的变形。

建模顺序应是先验收小幅眼球运动，再加入头颈联动，最后校验斜向组合与眨眼。更大角度若不能保持鼻口透视和眼睑遮挡，应改用经过验收、带眼球和头颈绑定的3D模型。

绿底可帮助去背景，但不会自动生成眼球图层、被遮挡区域或可编辑骨骼。现有视频保留为外观及动作参考，不承诺能直接变成任意角度的实时模型。本次未生成这些新素材、未调用付费建模服务，也未修改另一任务的3D资料。
