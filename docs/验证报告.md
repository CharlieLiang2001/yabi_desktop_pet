# 亚比桌宠 4.2 陪伴增强版验证报告

验证日期：2026-09-01（Asia/Shanghai）

## 构建与素材回归

- 使用 Windows 自带 .NET Framework x64 C# 编译器生成单文件 WinExe，构建成功且无新增运行时依赖。
- 内嵌4.2动作包：站立、眨眼、站立到坐下、坐姿、环顾、坐姿到睡眠、睡眠到坐姿、睡姿，以及七方向坐姿注视。
- 两段新增绿幕视频分别按实际画面识别为 `sit_to_sleep`（121帧）和 `sleep_to_sit`（193帧），以24fps完整播放。
- 新增动作采用独立色键抠图、软边去绿和完整身体帧，不做局部头部拼接、静态身体覆盖或尾巴拉伸。
- 两个动作使用480×480过渡画布；首尾帧与坐姿/睡姿稳定帧逐像素一致，窗口缩放时保持底部中心锚点。
- 深色、蓝色和透明棋盘接触表检查通过；坐→睡与睡→坐的峰值残留绿边比例分别为0.8114%和0.0307%，未见明显尾巴断裂。
- `AnimationCatalog.HasClip` 可安全查询 `feed`、`pet`、`play` 等可选槽位；照顾素材缺失时使用状态与气泡反馈。

## GUI与交互

- `--test-features` 实际创建主窗口、状态卡和五页设置窗口并正常退出，退出码0；测试模式使用独立单实例锁，不会与用户正在运行的亚比冲突。
- 状态卡快照确认等级、亲密度、三项需求条、喂食/休息/摸摸和专注按钮完整可见，无文字截断。
- 设置窗口常规、提醒和数据页快照确认页签、滚动区域、自定义提醒、统计、成就、导出与重置按钮布局正常。
- 单击由340ms延迟识别，拖动超过系统阈值会取消单击；双击会取消状态卡并继续执行站立/坐下/唤醒。
- 位置锁定仅禁止拖动，不禁止单击状态卡；拖动结束后按18 DIP吸附当前显示器工作区。
- 多显示器保存设备名和相对位置；目标显示器不存在时回退到主显示器并限制在可见工作区。
- 右键菜单重组为动作、照顾、提醒与专注、桌面与外观、设置、隐藏和退出；托盘保留显示、行为、穿透、设置、喂食和退出。
- Windows自动化接口不能枚举透明无边框主窗口，因此透明猫本体沿用4.1实机截图结论；本版没有改动该窗口渲染或角色帧。

## 性能与稳定性

- 32秒加速陪伴循环覆盖站立、坐下、新增趴睡转场和新增唤醒转场，退出码0。
- 加速循环14秒采样：平均CPU 3.68%，最大工作集76.6 MiB，结束工作集67.6 MiB。
- 安静睡姿5秒采样：启动清理后平均CPU约0%，工作集约4.9 MiB。
- 启动后执行一次空闲内存整理；动作结束仍保持有界帧缓存和工作集回收。
- 提醒、养成和设置均为本地逻辑，无网络访问和声音播放。

## 尚未覆盖的实体环境

- 当前只连接一个可见桌面工作区；多显示器拔插、不同DPI显示器间跨屏拖动通过代码路径与边界计算验证，未进行实体双屏操作。
- 开机启动通过当前用户注册表实现；自动测试只验证服务接口，不写入真实启动项。
