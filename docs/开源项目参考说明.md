# 开源项目参考说明

亚比桌宠 4.2 只参考以下项目的产品与架构思路，没有复制其源码、资源、角色或品牌元素：

- [VPet](https://github.com/LorisYounger/VPet)：参考状态决策与渲染职责分离的思路。
- [Shimeji-ee](https://github.com/gil/shimeji-ee)：参考“动作具有起始姿势、结束姿势与序列完成回调”的行为组织方式。
- [BongoCat Next](https://github.com/liwenka1/bongo-cat-next)：参考把鼠标跟踪作为独立开关，以及透明窗口、托盘与快捷键的桌面交互方式。

本工程继续使用轻量 WPF，但实现、动作清单、缓存、状态机、养成、提醒和桌面集成均针对亚比独立编写。最终角色画面仅来自用户提供的三张图片与三段视频。
