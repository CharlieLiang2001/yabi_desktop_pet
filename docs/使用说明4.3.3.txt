亚比桌宠 4.3.3 · 注视修复版

先从托盘菜单退出旧版，再双击本版 EXE。便携 ZIP 请先完整解压。
不需要安装 Python 或其他新运行环境，无管理员权限要求，离线静音运行。

本次修复
1. 修复进入鼠标注视后整只猫变透明：注视材质现在正确输出猫本体的透明通道，背景仍透明。
2. 注视使用独立稳定姿势纹理，不再冻结视频共用的图片缓冲区，避免切回视频时报错。
3. 提高近距离鼠标移动的响应和眼周跟随幅度；身体、爪子和尾巴仍保持固定。

使用
右键亚比 → 鼠标注视 → 实时视线跟随（站立 / 坐姿）。
不需要开启互动面板，也不需要停留在某个方向。站立、坐姿空闲时均可跟随。
拖动、睡眠、其他动作、菜单/设置、专注免打扰和跨屏时暂停；恢复空闲后继续。
原来的拖动、双击姿势切换、托盘、提醒、养成和快捷键保留。
Ctrl+Alt+P 切换点击穿透；Ctrl+Alt+Q 退出。
本版沿用已有位置、大小、透明度和养成数据，不重置设置，不修改开机启动选择。

边界
这是照片纹理的有限连续形变，不是独立眼球或真正的 3D 转头模型。
提高幅度不等于补齐真实侧脸或独立眼球素材；播放原有视频时注视仍会暂停。
三张图片、全部视频和原始动作包未重新生成、抠图或替换。
程序未数字签名；仅从本工作区提供的文件运行，不需要关闭安全软件。
