# 亚比桌宠 4.3 验证报告

验证日期：2026-09-07。环境：Windows 11 x64，系统版本 10.0.26200，20 个逻辑处理器。

## 结论

4.3 已接入新素材与自然互动，可交付本机试用。功能验证通过；最终这一轮空闲平均工作集低于 150 MiB，但私有内存与启动/动画峰值仍超过这一数值，不能把本版描述为“所有内存占用均低于 150 MB”。本报告不代表所有 Windows 10/11、多显示器和显卡环境的兼容性认证。

## 素材

- 五个原始视频规范复制后记录 SHA-256，原文件和 4.2 归档不变。
- 新增 821 张完整全身透明帧；新增 8 个动作定义，其中左、右、上方向引用同一个完整环顾母片，不重复存储母片帧。
- 新帧统一 320×480；所有新帧通过尺寸、透明四角、边界透明、首尾包围盒和方向段偏移检查。深色、蓝色、透明棋盘预览已输出。
- 抽样检查喂食、摸摸、舔爪、挠耳和环顾接触图：猫本体、尾端与四肢可见，无整片绿底矩形；没有叠加静态头部或尾巴。尾区像素检查是辅助指标，不等于逐根毛发都能完美保留。
- 新视频按帧时间戳播放；完整动作约 5、5、6、6、12 秒。方向段保留完整转头及回正，不变速、不局部拼接。段边界共用端点帧，末帧采样带来的几十分之一秒差异不表示缩短动作。
- 动作包仅包含图像与清单，不含音轨。标准/节能显示采样不同，但播放总时长独立于显示帧率。

资产校验依据：包内 `验证资料/validation43.json`；原始视频哈希、透明边缘统计、画布锚点和动作包哈希均在其中。

## 功能验证

- 最终构建自检：PASS，0 个失败。覆盖设置迁移及往返保存、自然注视驻留/死区/镜像/跨屏抑制/冷却/重新触发、单条最新请求队列、时间戳播放、养成/提醒既有测试。
- 标准模式原生 WPF 回归：完成两轮新动作；验证等待中的喂食被摸摸取代时不错误结算、有效照顾只记一次、冷却阻止重复结算、预览不刷经验。
- 最终构建追加节能模式回归：同样完成两轮并通过故障恢复。8 个新动作在两种模式下的播放时长中位数最大差 0.124 秒，未因节能而加速或缩短；微小变长来自显示采样和调度间隔。详见 `verification-summary.json`。
- 故意注入一帧解码失败：回退到稳定姿势，后续挠耳仍能播放；没有出现阻断启动或操作的错误对话框。这一次预期故障在日志中标为 `failed groom`，不是正常运行错误。
- 加速自动陪伴测试运行 180 秒：完成三轮睡眠→坐姿→站立流程，并进入第四轮睡眠；无非注入播放失败。加速的只有行为等待时间，动作仍按完整原速播放。
- 修复了自动起立反复推迟睡眠截止时间的问题，并增加回归测试。
- 界面快照检查：状态卡、动作库、五页设置、注视测试说明、提醒气泡、右键菜单；冷却文案不再截断，新动作优先展示，说明可换行。
- 本机验证了原生窗口可见且绑定猫图片、隐藏/恢复、置顶开关、镜像、点击穿透设置路径和解码失败恢复。

所有自动测试使用隔离的内存设置与养成对象，没有修改真实开机启动项，也没有重置用户养成进度。

## 性能

采样说明：每秒读取进程工作集、私有内存和累计 CPU；空闲统计排除前 20 秒的启动/入睡转场。CPU 用“一个逻辑核心占用 100%”口径，未除以 20，不能直接与任务管理器的整机百分比混用。内存用 MiB（1,048,576 字节）。测试没有调用 `EmptyWorkingSet` 或强制 GC 来制造低读数。

| 场景 | 工作集均值 / 峰值 | 私有内存均值 | 单核心 CPU 均值 | 说明 |
| --- | --- | --- | --- | --- |
| 标准模式连续新动作 | 189.84 / 211.12 MiB | 174.79 MiB | 8.44% | 175 秒，连续播放，不是空闲 |
| 标准模式加速陪伴 | 185.06 / 205.87 MiB | 168.63 MiB | 6.75% | 180 秒，包含多轮完整转场 |
| 节能模式连续新动作 | 192.31 / 225.55 MiB | 177.22 MiB | 7.32% | 最终构建，178 秒 |
| 标准模式睡姿空闲 | 127.95 / 208.56 MiB | 183.39 MiB | 0.37% | 最终构建，51 秒；峰值包含启动及入睡转场 |

首个猫窗口绘制在本机测试中约 0.7–1.2 秒，原生 `IsWindowVisible=True` 且 `HasPetBitmap=True`。这是已运行环境的启动实测，不是清空系统文件缓存后的冷启动保证。工作集会受 Windows 内存调度影响，不把这一轮的 128 MiB 均值保证为所有机器或每次运行的固定值。

运行时已改为从 EXE 的文件资源区按需读 ZIP、12 帧有界像素缓存、复用显示画布、PNG 压缩数据单次分配。连续运行中没有观察到工作集随每轮动作持续上涨，但数分钟测试不能代替数小时泄漏压力测试。后续仍需进一步压低 WPF/解码的常驻与瞬时占用。

## 尚未覆盖或未改变

- 未在独立 Windows 10 干净虚拟机中验证；未完成实体显示器拔插、混合 DPI、多显示器边缘拖动的人工验收。
- 拖动/双击和快捷键保留原有实现；物理鼠标手感、第三方热键冲突、Windows 通知勿扰造成的托盘通知抑制仍需使用中确认。没有把程序内调用测试写成完整的物理输入测试。
- 4.2 的旧站立/坐姿/睡姿及旧转场画面未重新绘制。旧素材原有尾部细节、浅边和生成视频自身形变，不宣称已全部修复；新动作使用全身画面，保留源视频的自然身体联动。
- 自然注视不是实时追踪：400 ms 只是方向驻留门槛，视频原本的前置停顿仍保留。下方无可靠素材时不触发，不伪造低头动作。
- EXE 未进行商业代码签名，大小约 156 MiB；完全离线、静音，不要求管理员权限。升级前需退出旧版，避免已有单实例弹出“亚比已经在桌面上啦”。

## 交付校验

打包脚本以实际生成的独立 EXE 和 ZIP 内 EXE 重新计算 SHA-256，并检查 ZIP 完整性；任一不一致即停止。最终值见同目录 `亚比桌宠4.3_自然互动版_SHA256.txt`。便携 ZIP 同时包含说明、报告、动作预览、功能快照与测试证据。
