# 亚比桌宠 4.3.3 · 注视修复验证

验证日期：2026-09-15。环境：Windows 11 家庭版 64 位，10.0.26200，系统 .NET Framework/WPF。

## 结论

复现并修复了“进入注视后猫变透明”和“注视后切视频抛出冻结对象异常”。本版仍是有界照片形变，增强了近距离跟随响应，但不是独立眼球或真实三维转头；观感仍需用户确认。

## 可复现证据

| 检查 | 结果 |
| --- | --- |
| 旧版新增回归测试 | 56 项失败：猫本体 alpha 丢失、无效预乘颜色、视频缓冲区被冻结 |
| 修复版全部自检 | PASS，0 失败 |

| 真实桌面深色/浅色背景合成 | 猫可见；不是仅从透明 PNG 预览推断 |
| 用户透明度 60% | 真实桌面合成可见，没有降为全透明 |
| 两轮注视↔眨眼/坐下/起立 | 视频缓冲区保持可写，无冻结异常 |

标准模式站立正面截图有 18,306 个接近不透明的猫本体像素；旧版对应截图为 0。修复后所有方向的“有 RGB 但 alpha 为 0”像素数量为 0。详见包内 gaze-verification.json、gaze-render/render-result.txt、gaze/result.txt 和 gaze-eco/result.txt。

测试使用独立内存设置/养成对象和测试单实例锁；鼠标坐标注入，没有移动系统指针、修改开机启动项或用户养成数据。真实桌面截取仅限桌宠所在区域，后方是测试自建的纯色窗口。

## 性能

标准/节能启动首张窗口分别为 1,044.3 / 637.5 毫秒，仅代表本机本次运行。

标准注视混合测试平均工作集 199.07 MiB、峰值 215.81 MiB，CPU 为单逻辑核心口径 8.06%；节能平均工作集 187.47 MiB、峰值 203.70 MiB，CPU 为 6.58%。混合测试包括完整视频、设置面板和截屏，不能当作纯空闲指标，也未达到此前 150 MiB 的内存目标。

完整原有动作回归平均工作集 169.33 MiB，CPU 为单核心口径 8.18%；日志中的一次 failed groom 为有意注入。原有测试器报告标题仍为“4.3 native regression”，本次执行的是 4.3.3 EXE，日期和完整轨迹见随包证据。

空闲采样 50.93 秒，排除前 20 秒后平均工作集 163.87 MiB，峰值 169.38 MiB，平均私有内存 161.27 MiB，CPU 为单核心口径 0.53%。这不是长期压力测试，也没有达到 150 MiB 内存目标。

未完成数小时压力、Windows 10 实机或多台显示器混合 DPI 验证。
