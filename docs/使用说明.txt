亚比桌宠 4.2 · 陪伴增强版
========================

适用系统：Windows 10 / Windows 11 x64
运行方式：双击“亚比桌宠4.2_陪伴增强版.exe”。亚比会直接出现在桌面上，不会打开主对话框。

基本操作
--------
1. 单击亚比：打开状态卡，查看等级、亲密度、饱腹、精力和心情。
2. 左键按住亚比：拖动位置；可在设置中锁定位置或关闭边缘吸附。
3. 双击亚比：在站立与坐姿间切换；睡觉时双击唤醒。
4. 右键亚比：打开动作、照顾、提醒、桌面与外观菜单。
5. 状态卡可执行喂食、休息、摸摸和开始/暂停专注。

养成规则
--------
- 饱腹、精力、心情首次均为80，只在程序运行时变化，关闭亚比后不会继续下降。
- 饱腹每6分钟下降1点；喂食增加25点，冷却20分钟。
- 精力每8分钟下降1点；睡眠时停止下降并每2分钟恢复1点。
- 心情每10分钟下降1点；摸摸增加15点，冷却5分钟。
- 有效照顾、完成提醒和累计陪伴可获得亲密度；每100点提升一级，最高99级。
- 低需求不会让亚比生病、消失、锁定功能或降低等级。

提醒与专注
----------
- 喝水和伸展提醒默认关闭，开启后默认间隔分别为45和60分钟。
- 专注计时默认25分钟，支持暂停、继续、重置以及延后5/10/30分钟。
- 设置页最多可添加5个自定义提醒，间隔范围5–240分钟。
- 到点时亚比会显示气泡；若亚比被隐藏或开启点击穿透，会同时显示托盘通知。

设置
----
- 五页设置面板：常规、陪伴、提醒、外观、数据。
- 支持开机启动、始终置顶、锁定位置、边缘吸附、安静/正常/活泼互动频率。
- 功耗模式支持自动、标准和节能；自动模式在电池供电时降低刷新率。
- 可编辑最多50句随机台词，每句最多80字。
- 数据页可查看今日/累计陪伴、互动、提醒、连续天数和成就，并支持导出或重置养成数据。

快捷键
------
Ctrl+Alt+H  显示 / 隐藏亚比
Ctrl+Alt+P  开启 / 关闭鼠标点击穿透
Ctrl+Alt+Q  退出亚比

数据与隐私
----------
- 设置保存在 %APPDATA%\YabiDesktopPet\settings.xml。
- 养成数据保存在 %APPDATA%\YabiDesktopPet\profile.xml。
- 数据只保存在本机，不联网、不上传、完全静音。
- 若养成数据损坏，程序会保留 profile.corrupt-时间.xml 备份并使用安全默认值启动。
- 旧版位置、大小、透明度、镜像、行为和鼠标注视设置会自动迁移。

素材说明
--------
- 本版使用三张写实图片和五段完整视频；新增“坐姿到趴睡”与“趴睡到坐姿”绿幕动作，没有拼接局部头部或拉伸尾巴。
- 睡觉时会先从站立过渡到坐姿，再播放坐姿到趴睡；唤醒时播放趴睡到坐姿，再回到站立。
- 新增动作使用独立480×480透明过渡画布，切换纵向坐姿与横向睡姿时保持桌宠底部中心不变。
- 照顾类专用动作素材仍缺失时，喂食、摸摸等功能使用气泡和状态反馈。
- EXE 未做商业代码签名；如 SmartScreen 提示，请先核对包内 SHA-256。

退出方式：右键菜单“退出亚比”、托盘菜单“退出亚比”，或按 Ctrl+Alt+Q。
